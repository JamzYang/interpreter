## 一、完整音频流向图
```
                    [我们的APP]
                         ↑ 
                         ↓
[A的麦克风] → [VB-CABLE Input] → [翻译处理] → [VB-CABLE Output] → [通讯软件] → [网络] → [B听到英文]
                                                                            ↑
[B的麦克风] → [英文语音] → [网络] → [通讯软件] → [VB-CABLE Input] → [翻译处理] → [VB-CABLE Output] → [A听到中文]
                                                        ↓
                                                  [我们的APP]
```

## 二、详细流程说明

### 1. A说中文的情况（中 → 英）
1. A说中文 → 被VB-CABLE Input捕获
2. 我们的APP从VB-CABLE Input读取音频
3. 进行STT/翻译/TTS处理
4. 生成英文语音输出到VB-CABLE Output
5. 通讯软件从VB-CABLE Output获取音频
6. B通过通讯软件听到英文

### 2. B说英文的情况（英 → 中）
1. B说英文 → 通过网络传输
2. 通讯软件播放英文语音 → 被VB-CABLE Input捕获
3. 我们的APP从VB-CABLE Input读取音频
4. 进行STT/翻译/TTS处理
5. 生成中文语音输出到VB-CABLE Output
6. A通过VB-CABLE Output听到中文

## 三、关键点说明
1. 需要两个VB-CABLE设备：
   - Input设备：捕获原始音频
   - Output设备：输出翻译后的音频

2. 音频路由设置：
   - 将系统麦克风输入设置为VB-CABLE Input
   - 将系统音频输出设置为VB-CABLE Output
   - 通讯软件使用这些虚拟设备

3. APP处理逻辑：
   - 持续监听VB-CABLE Input
   - 实时处理音频数据
   - 输出到VB-CABLE Output
