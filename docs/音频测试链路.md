# 音频测试链路说明

## 一、完整测试链路
```
[物理麦克风] → [APP] → [CABLE Output] → [CABLE Input] → [APP] → [物理扬声器]
```

## 二、测试阶段说明

### 1. 说话测试阶段
```
[物理麦克风] → [APP] → [CABLE Output]
```
- 用户对着物理麦克风说话
- APP 捕获音频并处理（未来会加入 LLM 翻译）
- 处理后的音频输出到 CABLE Output（系统默认录制设备）

### 2. 音频回环阶段
```
[CABLE Output] → [CABLE Input]
```
- CABLE Output 作为系统默认录制设备
- CABLE Input 作为系统默认播放设备
- 音频自动从 Output 传输到 Input

### 3. 听到测试阶段
```
[CABLE Input] → [APP] → [物理扬声器]
```
- APP 从 CABLE Input 获取音频
- 再次处理音频（未来是另一个方向的翻译）
- 通过物理扬声器播放出来

## 三、测试目的
1. 验证整个音频链路是否通畅
2. 测试音频质量和延迟
3. 确保双向翻译的基础设施正常工作

## 四、测试指标
1. 音频延迟：从说话到听到的时间差
2. 音频质量：信号强度和清晰度
3. 设备连接：各个设备的连接状态

## 五、常见问题排查
1. 确保系统音频设置正确
   - CABLE Input 为默认播放设备
   - CABLE Output 为默认录制设备

2. 检查 APP 设置
   - 录制设备选择物理麦克风
   - 播放设备选择物理扬声器

3. 信号检测
   - 麦克风信号强度是否足够
   - 是否存在回音或噪音
