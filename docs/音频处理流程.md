# 音频代理翻译APP - 核心流程

## 1. 音频拦截和处理流程

### 输入方向（说话）
1. 用户说话 -> 被VB-CABLE Input捕获
2. APP从VB-CABLE Input读取音频数据
3. 音频转文字(STT)
4. 文字翻译(Translation)
5. 文字转语音(TTS)
6. 翻译后的音频输出到VB-CABLE Output
7. 通讯软件从VB-CABLE Output获取并传输音频

### 输出方向（听到对方说话）
1. 对方通过通讯软件发送语音
2. 通讯软件播放音频 -> 被VB-CABLE Input捕获
3. APP从VB-CABLE Input读取音频数据
4. 音频转文字(STT)
5. 文字翻译(Translation)
6. 文字转语音(TTS)
7. 翻译后的音频输出到VB-CABLE Output
8. 用户通过VB-CABLE Output听到翻译后的语音
